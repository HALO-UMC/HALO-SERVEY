# HALO 부모님 이해도 설문 — React/Vite

부스 대기 시간에 모바일 웹 또는 태블릿 키오스크로 사용할 수 있는 설문 프로젝트입니다.

## 주요 기능

- 어머니 / 아버지 / 부모님 대상 선택
- 감정적인 깊이를 가진 10개 질문
- 0~2점 선택형 응답
- 중간 이탈 시 `localStorage` 자동 저장 및 이어하기
- 총점 기반 부모님 이해도 결과
- 가장 낮은 점수 + 마지막 마음 선택을 결합한 스토리북 추천
- 추천 테마 1개와 보조 테마 1개 표시
- 방문자가 직접 적은 질문 결과 화면 노출
- Web Share API 및 클립보드 공유
- 부스 진행자 전용 대형 결과 화면
- 굿즈 전달 완료 후 한 번에 초기화
- 모바일/태블릿/데스크톱 반응형
- 모션 최소화 설정 지원

## 배포

정적 빌드 결과물인 `dist` 폴더를 Vercel, Netlify 또는 GitHub Pages에 배포할 수 있습니다.

Vercel에서는 프로젝트를 연결한 후 다음 값을 사용합니다.

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`

## 핵심 파일

- `src/data/questions.js`: 질문과 답변 선택지
- `src/data/themes.js`: 테마명, 색상, 설명, 첫 질문
- `src/App.jsx`: 설문 상태와 추천 로직
- `src/components/StaffScreen.jsx`: 부스 진행자 확인 화면
- `src/styles.css`: HALO UI 전체 스타일

## 추천 로직

1. 10개 질문별 점수를 계산합니다.
2. 점수가 가장 낮은 질문과 연결된 테마를 우선 추천합니다.
3. 최저 점수가 같은 경우 마지막에 선택한 ‘가장 마음에 남은 이야기’를 우선합니다.
4. 그다음 낮은 점수의 테마를 보조 추천으로 보여줍니다.
5. 굿즈는 첫 번째 추천 테마를 기준으로 지급합니다.

## 개인정보

- 로그인과 이름 입력이 없습니다.
- 답변은 서버로 전송되지 않습니다.
- 작성 중 데이터만 브라우저 `localStorage`에 임시 저장됩니다.
- 설문 완료 또는 ‘다음 방문자’ 버튼 사용 시 데이터가 삭제됩니다.

## 실제 운영 전 교체할 요소

- 현재 CSS 캐릭터를 실제 HALO 테마 캐릭터 PNG/WebP로 교체
- 실제 서비스 URL 또는 앱 설치 QR 연결
- 행사 로고와 부스 안내 문구 반영
- 추천 테마별 포토카드 재고 코드 연결
- 필요 시 Firebase/Supabase를 이용한 익명 통계 저장
