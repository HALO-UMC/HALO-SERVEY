# HALO 부모님 이해도 설문 앱

부스 대기 시간에 사용할 수 있는 모바일 웹 설문 MVP입니다.

## 포함 파일

- `index.html`: 설문 웹 앱
- `styles.css`: HALO 스타일
- `script.js`: 문항, 점수, 추천 테마 로직
- `print-survey.html`: A4 인쇄용 종이 설문지

## 현재 추천 로직

- 총점: 10문항 × 0~2점 = 0~20점
- 이해도 결과: 총점 구간으로 결정
- 추천 테마: 가장 낮은 점수의 문항과 연결된 테마
- 최저 점수가 여러 개면 사용자가 가장 먼저 해보고 싶은 행동을 선택

## 개인정보

현재 버전은 서버 저장 기능이 없습니다. 새로고침하거나 다시 시작하면 답변은 초기화됩니다.
